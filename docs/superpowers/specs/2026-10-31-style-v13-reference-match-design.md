## 1. 意图与为什么

v12 已经脱离白模：有四色材质、倒角、螺丝、布尔窗口、旋转料斗。但它的造型语言是**工业硬表面**——方盒本体、平面面板拧上去、4 mm 硬分缝、可见紧固件。

用户给的参考图是另一种语言：**圆润软塑料家电**。整块包裹的外壳、大圆角、几乎看不到分缝、竖椭圆大窗里浮着一团彩色星云、橙色肉感夹爪、短圆出料口、深色矮底座。

目标是让现有资产在造型与配色上向参考图靠拢。**不是重做动画**——v12 已有 327 帧、17 条动作的定稿动画，重新制作动画没有任何收益。

为什么现在做：v12 的造型只从主镜位（`Cam_Hero`，front-right）看过。实测从背面看，它是一台裸灰盒子 + 薄荷板边缘露成一圈线框 + 一块扁平的棕色板当滑道，还有四件几何悬浮在机器后方。**这套资产目前换任何一个机位都不成立**，这是先于风格问题要解决的事（见 §4）。

## 2. 目标 / 非目标 / 反目标

### 目标

| ID | 目标 | 判据 |
|---|---|---|
| G1 | 造型语言从「硬边分件」转到「圆润一体」 | 主镜位 3 m 外与参考图并排，读作同一物种 |
| G2 | 配色对齐参考图 | 采样色差在 §5 合同内 |
| G3 | 全角度成立 | 正/侧/后/顶四个机位渲染无悬浮件、无裸面、无破面、无穿透 |
| G4 | 动画完全不变 | 327f、17 条 action、循环端点 f327 vs f1 差值 = 0.000000 |
| G5 | 交互接触不变 | 夹爪闭/开两档接触距离仍在容差内（见 §6 P3） |

### 非目标

- **不做材质/贴图**。用户明确：先 modeling。材质停在现有 flat baseColor 即可，只做配色数值校正，不加 AO 烘焙、不加贴图。
- 不做新动画、不改时序、不改缓动。
- 不改镜头与灯光装置。验收渲图允许临时加检查相机，但不写入交付 `.blend` 的默认相机。
- 不追像素级 1:1。参考图是 AI 生成，没有几何真值，无法作为度量基准。

### 反目标（技术跑通也算失败）

- 动画翻车：接触点漂移、循环断裂、显隐/缩放关键帧失效。
- 造型很像但抓空了：为了外形圆润把爪子改到抓不住产品。
- 面数失控：为圆润感堆细分，把 18k tri 推到 25k 以上。
- 单机位成立、换角度就露馅（这正是 v12 现在的状态）。

## 3. 约束

### 3.1 资产与数据

- 基准文件 `hero_animation_v12_style.blend`；`hero_animation_v6_retime.blend` 只读，不改不删。
- 不得修改任何 `*Action` / `*Action_V2` 动画数据块。
- 不得修改受动画驱动的对象的 origin、rotation 关键帧、父子层级。
- 可自由改：mesh 顶点/拓扑、静态造型件的对象变换、新增或删除纯静态造型件。
- **`Machine_Chute` 不属于「静态造型件」。** 它挂在 `Machine_OutputChute` 空物体下，而后者被 `Machine_OutputChuteAction_V2` 驱动（3 条 F-Curve、52 键）。改它要走完整的动画回归。
- **`Product` 的位置/缩放/显隐全部由 `ProductAction.001_V2` 的 78 个键钉死**（通道：hide_render / hide_viewport / location / scale），不得改动。
- 参考图**只有三个视图**：正视图、3/4 透视、俯视图。**没有侧视、没有背视**（用户已确认第三屏是俯视，此前误判为背视）。深度信息需自行推定。

### 3.2 比例的处理方式（用户裁定）

> 「我只是锁定比例防止动画翻车，但是不影响动画的话可以随便改。」

即：**比例本身不是硬约束，动画安全才是。** 造型可以推近参考图的瘦高体型与大窗，只要不破坏动画与接触。这解开了原本最紧的一道锁。

### 3.3 环境

- **必须用 `G:\Blender\blender-5.4.0-alpha\blender.exe`。** `hero_animation_v12_style.blend` 由 Blender 504.3（即 5.4.0-alpha）写入，用 5.3.0 打开会报 `WARNING File written by newer Blender binary (504.3), expect loss of data!`。两个版本都装在 `G:\Blender\` 下，且都不在 PATH 上，必须用绝对路径调用。
- Blender 4.4+ 的分槽 action（slotted actions）已移除 `Action.fcurves`，脚本取 F-Curve 必须走 `action.layers[].strips[].channelbags[].fcurves`。直接用 `a.fcurves` 会抛 `AttributeError: 'Action' object has no attribute 'fcurves'`。
- MCP addon 监听 9876，交互式 Blender 会话当前持有一个未保存的脏场景（`filepath=""`），**打开任何 `.blend` 前必须先处理**，否则丢失现场。
- 导出：GLB，`export_apply=True`。
- 基线审计脚本：`qa_v2/v13_baseline_audit.py`，输出 `qa_v2/v13_baseline.json`。用它做每阶段回归比对。

**结论：产品在 f232–f286 之间需要滑道提供支撑，共约 54 帧。** 如果把滑道缩到体宽的 0.35（≈0.81，即 x 1.16→1.97），产品从 f250（x 2.16）起就有 36 帧悬在空中。

而现有闸门帧是 f31 / f43 / f147 / f155——**那时产品还没出现（f232 才可见）**。四机位闸门如果只在动作帧拍，同样拍不到。**这是当前计划里一个漏洞：没有任何一条闸门能拦住「产品悬空」。**

**裁定（推荐）：滑道的支撑长度冻结在 x 1.16–3.40，但外观分段重做**——靠近机身的一段（约 x 1.16–2.1）做成参考图里那种短圆口橙色出料口，剩下的 x 2.1–3.40 做成细窄、低矮、颜色压暗的导轨，在主镜位里视觉权重降到很低。这样「短圆口」的观感成立，产品全程有支撑，一个 action 都不用碰。

**因此 §4.3 里的「滑道长 / 体宽 ≈ 0.35」这条放弃**，改为「可见出料口长度 / 体宽 ≈ 0.35」。

### 5.2 部件清单（P0 放大重看参考图后修正）

上一版这份清单有三处读错，**以本节为准**：

1. 圆润一体外壳，**正面整片奶油**，四角大圆角，无硬分缝
2. **薄荷不是环绕全机的环带**，而是三处局部：①顶面围绕斗颈的一圈**领圈** ②机身左右两侧竖窄面板 ③顶面横贯的一条弧带。薄荷是点缀，奶油是主色
3. 正面竖**超椭圆**大窗：厚炭边框 + 内圈青发光环 + 玻璃后一团粉/青星云。实测 H:W = 1.553，宽占体宽 0.542、高占体高 0.616 —— **它是正面的绝对主体，v12 的方窗 + 一圈细亮环完全不是这个东西（P2 整块重做）**
4. 顶部料斗：**奶油色，不是薄荷色**；宽浅、**厚卷唇**、壁厚明显；坐在奶油圆颈上，颈下才是薄荷领圈。v12 的薄壁开锥（能透视到对侧内壁）必须换掉
5. 左臂：奶油圆管 + 深炭球形肩/肘关节 + **橙色球腕 + 三根粗短指**（Q2 已定：两片对合 + 一根不带 action 的固定第三指）
6. 右侧出料口：**短勺状**，奶油壳 + **橙色内槽**，带一点上翘的圆唇，伸出量只有体宽的 0.677

## 12. 用户裁定（2026-10-31，已确认）

### Q1 · 壳体缩窄 → **走 B 折中**

**壳宽 2.32 → 1.80（正面 W:H ≈ 1.0）**，高度维持 1.80。

必须新增三处接驳件，否则臂根、料斗、滑道口会脱开：

| 接驳件 | 为什么必须 | 冻结量 |
|---|---|---|
| 肩舱 | 壳左面从 x=−1.16 收到 x=−0.90，而臂根 `Arm_Base` 占 x −1.136…−1.864 | **臂根世界坐标一字不动** |
| 出料口座 | 壳右面从 x=1.16 收到 x=0.90，而 `Machine_Chute` 起点在 x=1.16 | **滑道口 x=1.16 一字不动** |
| 料斗座 | 斗底 z≈2.35 被 `Idea` 落点（0, 0, 2.600，球半径 0.25）钉死 | **斗底高度与球落点不动** |

料斗口径：壳窄到 1.80 后，原 1.37 斗径占比变成 0.76（参考图目标 0.45）。**缩斗口前必须验算球能否仍从斗口通过、斗底 z 是否仍托住 `Idea`——这是 P1 的第一件事；验不过就维持原斗径，把取舍写进 `BUILD_NOTES.md`。**

### Q2 · 夹爪 → **走 B：两片对合 + 一根固定第三指**

- `Arm_Finger_L` / `Arm_Finger_R` 的 rotation 关键帧、origin、网格归属**一字不动**。
- 两片爪的网格重做成圆润粗短垫，外形像指，不改对合运动学。
- 腕部加一根**不带任何 action 的固定第三指**，只补剪影，使它读作三指整手。
- 接触判据固定成脚本后，要求闭合帧仍贴合 `Idea`、不穿透。

### Q3 · GLB 星云 → **走 A：不加贴图**

- 不加 UV、不烘贴图、不动材质域。
- 用 `Machine_WindowNoise1/2` 同款自发光网格堆伪星云，纯 modeling。
- 渲染版与 GLB 版观感差异必须写进 `BUILD_NOTES.md`，不假装一致。

### Q4 · 循环跳变 → **要修，按「补末帧值」方式**

根因已精确定位到一条曲线：

```
Machine_Hopper  action: Machine_HopperAction_V2  range (1.0, 242.652)
  location[2]  keys=26
    首键 (f1.00,  2.450000)
    末键 (f242.65, 2.455005)   <-- 与首键差 0.005005
```

**修法**：只把末键（f242.65）的 `location[2]` 值从 `2.455005` 改成 `2.450000`。**键数仍是 26，时间点一个不动，其它曲线一个不碰。**

`Outlet_Flap` 的 `rotation_euler[1]` 首末键都是 `−0.523599`，本身没错；它的 0.005005 是从父级链继承来的——改完 `Machine_Hopper` 末键，`Outlet_Flap` 的循环差会同时归零。**修完必须重跑基线脚本确认两者都变成 0。**

> 代价：料斗在 f242–f326 的保持段会比原来低 5 mm。5 mm 在一台 1.8 米高的机器上肉眼不可见，而循环不闭合是每循环跳一次的硬伤，两者不成比例。
