### 1. 底座 —— 当前是"桌板架"，不是底座

**参考图**（`review/v14/audit/cmp1_base.png` 左；`scratch/crops/ref_base.png`）
- 一体化深灰碗形底座：顶面与机身底面贴合，**侧面向内收成弧形凹面**（不是直壁盒）
- 底部 4 只短圆脚（前 2 后 2），脚是**圆截面**短柱，与底座平滑相接
- 底座整体**比机身略窄**（内收），高 ≈ 机身高的 0.1576
- 机身与底座之间**无缝隙**，是一条连续的外轮廓

**当前模型实测**（`hero_animation_v14_p19.blend`）

| 件 | 包围盒 | 体积 | 填充率 | 连通分量 |
|---|---|---|---|---|
| `Machine_Base` | x −0.925…0.925, y −0.80…0.80, z 0…0.288 | 0.10949 | **0.1284** | **4** |
| `Machine_Feet` | x ±0.7575, y ±0.61, z −0.10…0 | 0.00636 | **0.0344** | **4** |
| `P1_BaseBand` | x ±0.925, y ±0.825, z 0.26…0.444 | 0.55164 | 0.9822 | 1 |

问题清单：

1. **主体空心**。`Machine_Base` 填充率仅 12.8%，bbox 体积 0.852 而实体只有 0.109 —— 这是**两块桌板 + 支架**，不是实心底座。渲染 `review/v14/audit/base_only_3q.png` 清楚显示：一块大平板悬空，下面挂 4 片彼此不相连的零件。
2. **4 只脚不是底座的一部分**。`Machine_Feet` 是 4 个独立网格，填充率 3.4%（薄片），且位于 z −0.10…0 —— **完全在底座主体下方**，中间没有任何连接。渲染里能看到方片和圆柱各自悬空、互不相接。
3. **脚型不对**。参考是**圆截面短柱**，当前是薄方片（bbox 0.135×0.18×0.10）。
4. **`P1_BaseBand` 抢戏**。它 y 向 ±0.825 比底座本体 ±0.80 还宽 0.025，向外凸出一圈，形成一道突兀的台阶；参考图里底座是**向内收**的，没有外凸环。
5. **尺寸比例**。当前底座 z 高 0.288 + 脚 0.10 = 0.388；机身 z 0.26…2.72（高 2.46）→ 底座高/机身高 = 0.1577，与参考 0.1576 恰好吻合。**高度是对的，形状是错的。**
6. **倒角等级**。`Machine_Base` 用 0.025×3 段，对参考图那种大弧面明显偏小。

### 2. 螺丝孔 —— 沉孔做成了外凸螺帽

**参考图**（`scratch/crops/ref_screw_0.png`、`ref_screw_2.png`，10× 放大）
- 是**沉孔（countersink）**：一个圆形凹窝，有可见的内壁（上部亮环＝内壁受光）和窝底阴影
- 正视图 P0 共 **4 枚**，分布在面板四角附近：(252,432)、(492,432)、(248,762)、(496,763)，窝径约 13 px
- 顶视图 P2 另有 **4 枚**：(1440,463)、(1653,463)、(1441,640)、(1653,642)
- 颜色是**浅奶油色**（与面板同色系），不是深色

**当前模型实测**

| 项 | 实测值 |
|---|---|
| 螺帽数量 | **16 枚**（F/B/L/R 各 4 枚） |
| 单枚尺寸 | 0.056 × 0.011 × 0.056（12 边形头 + 一字槽，槽深 0.004） |
| 材质 | `MAT_Arm_Dark`（近黑） |
| 位置 | F/B 面 x=±0.78, y=±0.803；L/R 面 x=±0.903, y=±0.78；z = 0.533 / 2.447 |
| **沉孔** | **机身 `Machine_Body` 上没有任何布尔沉孔** |

问题清单：

1. **凹凸方向完全相反**。参考是凹窝，当前是**外凸 11 mm 的黑色螺帽**。渲染 `review/v14/audit/det_screw_up.png` 里它们像贴上去的黑豆子，与参考图的浅色凹窝毫无相似。
2. **数量多 4 倍且位置错**。参考是**每面 4 枚、窝径 13 px**（约占机身宽 1/23）；当前是 16 枚大螺帽挤在面板四角。
3. **颜色错**。参考螺钉是奶油色浅凹窝；当前是 `MAT_Arm_Dark` 近黑色，与奶油面板形成最强对比 —— 这正是渲染里"黑豆子"的来源。
4. **沉孔缺失**。`Machine_Body` 只有两个布尔：`OutletCut`（→`Cutter_Outlet`）和 `WindowCut`（→`Cutter_Window`）。**没有 ScrewCut**。螺帽是贴在表面的独立网格，没有嵌入。
5. 附带问题：`P1_Bolt_*` 各自独立成网格（16 个 mesh），与 `Arm_Base` 的做法一致但代价是 GLB 网格数；且 12 边形头在渲染里可见棱面。

### 4. 出料口 —— 当前是封闭实体

**参考图**（`scratch/crops/ref_outlet_top.png` P2 顶视 4×；`ref_spout_p0.png` P0 侧视）
- 橙腔是**真实凹槽**：顶视能看到内壁的自遮蔽渐变（靠边暗、中心亮），**外壁有厚度**，能看到槽口边缘的转折
- 橙腔被**奶油色唇框**完整包围，唇框厚且圆润；唇与橙之间有一道**暗缝**
- P0 侧视：橙色是一个 **L 形** —— 贴着机身立面有一段**竖直橙色腿**（z 1.12→2.09，高 0.97），到下方转成水平段，末端收成**圆勺**（z 1.19→1.48，最大宽 0.667）
- 出料口总长仅约 0.66 倍机身宽（P19 报告已确认）

**当前模型实测 —— 这是四处里最严重的问题**

射线检测（`scratch/probe_outlet.json`）：

```
DOWN_RAYS  x=1.0 (从 z=2.2 垂直向下)
  y=0.0  -> Machine_Chute@1.074, Machine_Chute@1.039, ESCAPE
  y=±0.38-> Machine_Chute@1.556, Machine_Chute@1.074, Machine_Chute@1.039
```

```
CHUTE 截面 (x=1.0, 世界 y/z)
  (±0.415, 1.039)  (±0.415, 1.556)  (±0.38, 1.074)  (±0.38, 1.556)
```

```
CHUTE_openness: boundary_edges=0, nonmanifold=0, signed_volume=-0.09042
```

关键结论：
1. **橙面 z=1.074 是平的**。从上方垂直打射线，在 y=0 处直接命中 1.074 就停 —— 说明 **z 1.074 以上是空的**？不，反过来读：射线在 1.074 命中（槽底内表面），再在 1.039 命中（槽底外表面），然后逃逸。**中间 1.074–1.556 的"槽"其实是实体**。截面点只有 4 对、且 y=±0.415（外壁）与 y=±0.38（内壁）之间 z 从 1.074 到 1.556 **是实心的**。
   → 橙面是一块 **z 1.039…1.556 的实心长方体**，顶面 z=1.074 处只是"地板上表面"，橙腔没有内壁、没有深度、不是槽。
2. **signed_volume = −0.09042（负号）** —— 法线整体朝内，是一个**翻转的封闭实体**。配合 boundary_edges=0 / nonmanifold=0，确认它是个**壳状闭合体**，不是管。
3. **口内视线被堵死**。渲染 `review/v14/audit/det_outlet_mouth.png`（从 x=3.6 朝 −X 看进嘴口）显示：橙侧壁、橙底，**正前方是一整片奶油色实体墙面**（机身内壁 `Machine_Body`），看不到任何开口。
4. **机身孔是盲孔**。`Cutter_Outlet` bbox x 0.74…1.24，而 `Machine_Body` 实体在 x=0.74 处仍在（射线 `bore_ray_from_inside_x0.3` 在 z=1.1…1.44 全部先命中 `Machine_Body@0.74`）。也就是**孔只挖到 x=0.74 就停了，机身内腔没被挖穿** —— 内壁是一堵实墙。
5. **去掉机身后再打射线**（`mouth_ray_nobody`）从 x=2.9 往 −X 打，z=1.1…1.5 全部 ESCAPE → 橙件自身内部**确实有贯通空腔**（沿 X 方向），但这个空腔**被机身的盲孔底堵住**，从外面看不见。
6. **附带**：`P1_OutletCollar` 是个 128 面环形唇，但 `P1_OutletRailL/R` 的 z 只到 1.320，橙件 z 到 1.556 → 橙件比奶油侧墙**高出 0.236**，参考图是奶油唇**包住**橙腔，关系相反。

## 二、修改方案

### 总体原则

沿用项目既定规矩（`OUTLET_REBUILD_PLAN.md` §7）：**先钉契约、再改件**，逐件微调只会把错台挪位置。以下每个部位先给出"契约表"（唯一真值），再给改法。

**共用操作约定**（沿用 `BUILD_NOTES.md` §8.5 已踩过的坑）：
- 换 `obj.data` 会**静默丢掉 material slots**，换网格后必须重新 `data.materials.append(...)` 并重设 `polygon.material_index`
- 新建 polygon 默认 `use_smooth=False`，要用 `shade_auto_smooth` 算子或逐面 `p.use_smooth=True`
- 严禁 `SUBSURF`（P18 面数从 26k 爆到 67k 的元凶）
- 布尔目标必须 `clear_outer`/`clear_inner` 正确，否则出反向绕序
- 三角面预算 60,000，当前 24,612（41%），**余量充足**

### 1. 底座重建

**契约表**

| 项 | 值 | 依据 |
|---|---|---|
| 底座外形 | 圆角矩形实心板，四周向内收弧 | 参考 P0/P1 |
| 底座顶面 | z = 0.288（与 `P1_BaseBand` 交接） | 保持现状 |
| 底座底面 | z = 0.02 | 脚高 0.10 保持现状 |
| 平面尺寸 | x ±0.90, y ±0.78 | 比机身（±0.90/±0.80）略窄 |
| 圆角 | 平面 R 0.16，竖向大弧 R 0.10 | 参考"内收弧面" |
| 脚 | 4 只，**圆柱截面** r=0.055，高 0.10，圆心 (±0.66, ±0.44) | 参考 P1 |
| 底座+脚/机身高 | 0.1576 | 现状已达标，改形不可动 |
| 倒角 | class A 0.05 × 3 段 | 与参考大弧面匹配 |
| `P1_BaseBand` | **删除**，或收到 y ±0.795 以内 | 参考无外凸环 |

**改法（网格编辑 + 修改器）**

1. **重建 `Machine_Base` 为实心**（替换现有空心架）：
   - 用 bmesh 建圆角矩形实体：8 段圆角平面轮廓 → 拉伸到 z 0.02…0.288 → 底面/侧面加一圈 **inset + 斜切**形成"内收弧面"
   - 或更稳的做法：建 0.02…0.288 的圆角矩形实体，加 **Bevel(width=0.10, segments=4)** 做竖向大弧
   - 材质 `MAT_Arm_Dark`，加 Bevel 0.05×3 + Smooth by Angle
2. **重建 `Machine_Feet` 为 4 只圆柱**：
   - 顶点 16 段圆截面，r=0.055，z −0.10…0.02（**上端嵌入底座 0.02，保证实体相接**，不是悬空）
   - 位置 (±0.66, ±0.44)，底部加 Bevel 0.012×2 做圆脚
   - 或更简：把脚并入底座网格做布尔并集，单件交付
3. **`P1_BaseBand`**：参考图底座无外凸环 → 建议删除；若保留作机身与底座的过渡，则 y 收到 ±0.795、z 压到 0.26…0.42
4. **`Machine_Base` 的 scale (0.34, 0.34, 0.192) 必须先 apply** —— 非均匀缩放会让 Bevel 宽度在 XY 和 Z 上变形（0.025 在 XY 实际只有 0.0085），重建时直接建世界尺寸并清零 scale

### 2. 螺丝孔重建

**契约表**

| 项 | 值 |
|---|---|
| 数量 | **每面 4 枚**，总计 16 枚（保留 16 这个数，但**位置与形态全改**） |
| 形态 | 沉孔（countersink），**不是外凸螺帽** |
| 窝外径 | 0.062（参考 13 px ÷ 机身 297 px × 1.8 = 0.079，取 0.062 略收） |
| 窝内径 | 0.030 |
| 窝深 | 0.016 |
| 沉头 | 锥面，窝底有 0.030 的平底 |
| 材质 | 与所在面板同色系（前面板用 `MAT_Body`，薄荷面板用 `MAT_Color_Mint`） |
| 位置 | **不再贴面板四角** → 移到参考图实测位 |

**改法（布尔运算）**

1. **建一个沉孔刀（cutter）**：
   - 圆锥台：顶半径 0.031 → 底半径 0.015，高 0.016，中心带 0.030 半径的平底
   - 布尔差（EXACT）打进面板 → 得到真正的凹窝
2. **在面板上打阵列**：
   - **前面板 `Machine_Body`（-Y 面）**：4 枚，按参考 P0 像素位换算 —— 机身 x 范围 1.8 对应像素 100…396（296 px），故 x_px=252 → x = (252−100)/296×1.8 − 0.9 = **−0.561**；x_px=492 → **+0.809**；z_px=432 → 机身 z 0.26…2.72 对应像素 382…787（405 px），z = 2.72 − (432−382)/405×2.46 = **2.418**；z_px=762 → **0.639**
     → 前面板 4 枚：**(−0.561, 2.418)、(+0.809, 2.418)、(−0.575, 0.639)、(+0.794, 0.639)**（y = −0.80）
   - **顶视 `P3f_TopSkin` / 顶部薄荷面**：4 枚，按 P2 实测 (1440,463)(1653,463)(1441,640)(1653,642) 换算
   - **左右面 `P1_MintStrip_L/R`**：各 4 枚，保持 z=0.533/2.447 一带
3. **删掉现有 16 个 `P1_Bolt_*` 网格** —— 它们是外凸螺帽，与沉孔互斥
4. 若希望窝底可见一颗小螺钉，则把螺钉做成**窝底以下**的独立小件（半径 0.012，藏在窝内），而不是贴在表面
5. 材质：沉孔本身用面板材质即可（布尔差自动继承）；如需加强可加 Ambient Occlusion 节点

### 4. 出料口重建（最关键）

**契约表**（依据参考 P0 侧视 + P2 顶视实测）

| 项 | 值 | 依据 |
|---|---|---|
| 结构 | **真实开口 + 通道**（非封闭实体） | 用户要求 + 参考橙腔自遮蔽渐变 |
| 机身面 | x = +0.90 | 现状正确 |
| 橙槽内腔 | y ±0.34，槽底 z 1.074，口沿 z 1.556 | 参考橙腔比例 |
| 唇框内腔 | y ±0.37，z 1.03…1.60（每侧留 0.03 缝） | 参考唇橙之间有暗缝 |
| 唇框外 | y ±0.52，z 0.97…1.63 | 奶油唇完整包住橙腔 |
| 竖直橙腿 | z 1.12…2.09（高 0.97），贴机身立面，厚 0.05 | 参考 P0 的 L 形竖腿 |
| 圆勺末端 | z 1.19…1.48，最大宽 0.667 | 参考 P0 末端收口 |
| 机身孔 | **必须挖穿**到机身内腔 | 用户要求"贯穿" |
| 通道净空 | 产品 0.70 宽 → 内腔 ≥ 0.78 | 参考比例 |

**改法（布尔 + 网格重建 + 新建件）**

**第 1 步：把 `Machine_Chute` 从封闭实体改成真正的 U 型槽**

当前 `Machine_Chute` 是 signed_volume **−0.090** 的翻转闭合壳（184 顶点 / 178 面 / 0 非流形边），顶面被封死。

- **方案 A（推荐，改网格）**：按 §3 的 U 形断面重新放样 —— 断面 = 内宽 0.76、槽底 1.039…1.074、两侧壁到 1.556 的 **U 形开放轮廓**（不是闭合矩形），沿 x 0.86…2.30 放样，两端开口。**U 形断面本身就是开口的**，天然解决"封闭实体"。
  - 顶点预算：8 断面点 × 24 站 = 192 顶点，与现状相当
  - 材质全 `MAT_Color_Amber`，每面 `use_smooth=True` + Smooth by Angle
  - **不用 SUBSURF**
- **方案 B（用布尔）**：保留现有件，用一个"内腔刀"（U 形棱柱，x 0.86…2.30，y ±0.38，z 1.074…1.60）做布尔差。**风险更高** —— 现状法线已翻转，EXACT 布尔在自交壳上容易失败。

**第 2 步：挖穿机身孔（这是"贯穿"的关键）**

- `Cutter_Outlet` 现在 x 只到 1.24、而 `Machine_Body` 在 x=0.74 仍是实体 → 孔底是一堵墙
- 改法：把 `Cutter_Outlet` 沿 −X **延伸贯穿机身**（x 从 0.74 改到 **−1.0**，确保与机身内腔贯通），y ±0.652 保持，z 1.023…1.452 保持
- 机身是 `Machine_Body` 的布尔宿主（`OutletCut` 修改器已在），**改 cutter 尺寸即可，布尔自动重算**
- ⚠️ 联动：`Cutter_Outlet` 是 `Machine_Body` 的子物体且带 `matrix_parent_inverse`，**改尺寸前先清空 `matrix_parent_inverse`**（`OUTLET_REBUILD_PLAN.md` §8.5 已记此坑），否则整把刀会位移
- **贯通验证**：`scene.ray_cast` 从机身内腔 (x=−0.5) 沿 +X 打，应在 z 1.10…1.44 区间一路 ESCAPE 出机身外

**第 3 步：重建奶油唇框（`P1_OutletCollar`）**

- 现状：128 面环，但 `P1_OutletRailL/R` 只到 z=1.320，橙件到 1.556 → 橙比奶油高 0.236，**关系反了**
- 改法：唇框做成**完整环带**，外 y ±0.52 / z 0.97…1.63，内腔 y ±0.37 / z 1.03…1.60，**橙槽从唇框内穿过**
- 唇与橙之间留 0.03 缝，缝内自然形成暗线（参考图的"暗缝"）
- 奶油唇**顶面必须高于橙槽口沿**（唇 1.63 > 橙 1.556），这样侧视才看到"奶油包住橙"

**第 4 步：补上参考图的 L 形竖腿与圆勺**

- 新建 `Machine_OutletLeg`（橙）：贴机身立面，z 1.12…2.09，厚 0.05，y ±0.34，与 `Machine_Chute` 的槽底在 x=0.90 处**连续相接**
- 新建 `Machine_OutletScoop`（橙）：末端收成圆勺，z 1.19…1.48，最大宽 0.667
- 现状 `P2_OutletBand`（z 1.60…2.09，高 0.49）**太短**（参考 0.97）且太薄（厚 0.03）→ 重建为 `Machine_OutletLeg` 的下段

**第 5 步：处理长托 `P1_ChuteRail`**

- 参考图**没有长托**。但产品要滑到 x≈2.46 才飞出，没有托会悬空
- **取舍方案**：保留 `P1_ChuteRail` 但把它做成**唇框的自然延伸**（同材质同弧度），而不是当前那块独立的**深灰哑光块**（`MAT_Arm_Dark`）—— 当前渲染里它就是那截突兀的黑色挡板，参考图完全没有
- 若追求严格还原参考：删 `P1_ChuteRail` + 把产品出料动画提前（在 f232 落入橙槽后立即下滑出唇框），并接受产品有一段短距离自由落体

**第 6 步：口径对齐**

- 现状 `P1_OutletRailL/R`（z 1.00…1.32，y ±0.417…0.51）与唇框功能重叠 → 合并进唇框，或删除后由唇框统一承担

### 3.2 打光建议

参考图是**柔和影棚光**：左上主光 + 大面积补光 + 无缝灰背景 + 底部接触阴影。

- 现状 `Cam_Hero` + 双太阳光 + world 0.051 的配置**渲染出来是平、硬的**，与参考的柔和感差很远 —— `STATUS.md` §6.4 已把打光列为"最弱环节"
- 建议沿用 P4 的三点式：**AREA_Key 620 W / AREA_Fill 170 W / AREA_Rim 360 W / sun 1.3，world 0.55/0.52/0.48，view transform Standard**
- **对深色底座**：加一盏低位 area light 从前方 30° 打，让内收弧面出现一条**渐变亮带** —— 参考图底座的立体感全靠这条带，缺了它实心底座也会显得扁
- **对沉孔**：正上方略微偏离轴心的 key light，能在内壁形成**可见的高光环**（参考图正是这个特征）；纯正对轴心会让窝底全黑、看不出是凹的
- **对橙腔**：不要补光直射腔内，否则自遮蔽渐变消失、槽会"看起来是平的"。让光从侧上方掠过，靠环境光遮蔽出深度
